# 시드 관심종목 알림

`watchlist.csv`의 종목을 평일(월~금) 08:00~20:00에 확인해서 (정규장 9:00~15:30은 15분마다, 프리·애프터마켓은 30분마다), 아래 두 조건을 모두 만족하면 ntfy로 폰과 PC에 알림을 보내요.

- 현재가가 20일 이동평균선 ±2% 안에 있음
- RSI(14)가 30 이하

같은 종목은 하루에 한 번만 알려요. 공휴일처럼 장이 안 열린 날은 건너뛰어요. 매수는 알림을 보고 직접 판단해서 하세요.

## 종목 바꾸기
관심종목 페이지에서 **CSV로 복사**를 누른 뒤, 이 저장소의 `watchlist.csv`를 열어 연필 아이콘으로 편집 → 전체 붙여넣기 → **Commit changes**.

## 조건 바꾸기
`alert.py` 맨 위의 `NEAR_PCT`(근접 범위 %), `RSI_MAX`(RSI 기준)를 고치면 돼요.

## 테스트
**Actions → 관심종목 감시 → Run workflow** 를 누르면 지금 상태가 바로 알림으로 와요.
