# 시드 관심종목 알림

`watchlist.csv`의 종목을 평일(월~금) 08:00~20:00에 20분마다 확인해서, 아래 두 조건을 모두 만족하면 ntfy로 폰과 PC에 알림을 보내요.

- 현재가가 20일 이동평균선 ±2% 안에 있음
- RSI(14)가 30 이하

조건이 이어지는 동안은 1시간마다 다시 알려요. 공휴일처럼 장이 안 열린 날은 건너뛰어요. 매수는 알림을 보고 직접 판단해서 하세요.

## 종목·알림선 바꾸기
시드 페이지에서 종목을 추가하거나 차트에 알림선을 그린 뒤 **CSV로 복사**를 누른 뒤, 이 저장소의 `watchlist.csv`를 열어 연필 아이콘으로 편집 → 전체 붙여넣기 → **Commit changes**.

## 조건 바꾸기
`alert.py` 맨 위의 `NEAR_PCT`(근접 범위 %), `RSI_MAX`(RSI 기준)를 고치면 돼요.

## 테스트
**Actions → 관심종목 감시 → Run workflow** 를 누르면 지금 상태가 바로 알림으로 와요.

## 차트
- 알림에는 그 순간의 일봉 차트(이동평균 5·10·20·30·60·120, 볼린저밴드) 이미지가 붙어 와요.
- 시드 페이지 차트용 데이터는 실행 때마다 `chart-data` 브랜치에 덮어써요. 시드는 평일 8~20시 매시 10분에 이 데이터로 업데이트돼요.

## 알림선
시드 차트에서 그린 선은 `watchlist.csv`의 `알림선` 칸에 `250000/210000`처럼 들어가요. 20분마다 1분봉으로 확인해서 가격이 그 선에 닿으면 (같은 선은 1시간이 지나 다시 닿으면 또) 차트 사진과 함께 알려요.

## 밴드·20일선 근접
현재가가 볼린저밴드 상단·하단 또는 20일선에 2% 안으로 다가오면 (같은 선은 1시간이 지나 다시 다가오면 또) 차트 사진과 함께 알려요. `alert.py`의 `LEVEL_PCT`로 범위를 바꿀 수 있어요.

## 기숙사 PC 실시간 감시
`pc` 폴더를 기숙사 PC에서 실행하면 정규장엔 실시간, 장외엔 1분마다 확인해요. 켜져 있는 동안 이 GitHub 감시는 알림을 쉬어요. 설정 방법은 `pc/README.md`.

## 3% 변동
전일 종가 대비 +3%, +6%… 또는 -3%, -6%… 단계를 그날 처음 넘을 때마다 알려요. `alert.py`의 `STEP_PCT`로 단위를 바꿀 수 있어요.
